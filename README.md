# Incoming Request Processing Workflow

An AI-powered customer request processing system built using Streamlit, Gemini AI, and SQLite.

## Features

- AI request classification
- Urgency prediction
- Department routing
- Workflow execution
- Case ID generation
- AI-generated acknowledgement email
- Request history dashboard
- CSV export

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- SQLite

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
